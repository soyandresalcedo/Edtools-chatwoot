# Railway AWS S3 Configuration

## Variables Required in Railway Dashboard

After deploying, configure these environment variables in your Railway dashboard:

### ✅ AWS S3 Storage
```bash
ACTIVE_STORAGE_SERVICE=amazon
AWS_ACCESS_KEY_ID=YOUR_AWS_ACCESS_KEY
AWS_SECRET_ACCESS_KEY=YOUR_AWS_SECRET_KEY
AWS_REGION=us-east-2
S3_BUCKET_NAME=edtools-storage-railway
```

### 📧 Amazon SES Email (SMTP)
```bash
MAILER_SENDER_EMAIL=noreply@yourdomain.com
SMTP_ADDRESS=email-smtp.us-east-1.amazonaws.com
SMTP_USERNAME=YOUR_SES_SMTP_USERNAME
SMTP_PASSWORD=YOUR_SES_SMTP_PASSWORD
```

**⚠️ Security Note**: Never commit actual credentials to git. Use Railway dashboard variables only.

### 🔧 Rails Core (Already configured)
```bash
SECRET_KEY_BASE=<auto-generated by Railway>
DEVISE_JWT_SECRET_KEY=<auto-generated by Railway>
DATABASE_URL=<auto-configured PostgreSQL>
REDIS_URL=<auto-configured Redis>
```

## AWS S3 Bucket Permissions

Your S3 bucket `edtools-storage-railway` needs these permissions:

### Bucket Policy (Replace YOUR_BUCKET_NAME):
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObject",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::YOUR_BUCKET_NAME/*"
        }
    ]
}
```

### CORS Configuration:
```json
[
    {
        "AllowedHeaders": ["*"],
        "AllowedMethods": ["GET", "PUT", "POST", "DELETE"],
        "AllowedOrigins": ["https://app.edtools.co"],
        "ExposeHeaders": ["ETag"],
        "MaxAgeSeconds": 3000
    }
]
```

## IAM User Permissions

Create an IAM user with these permissions:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "s3:GetObject",
                "s3:PutObject",
                "s3:DeleteObject",
                "s3:GetObjectAcl",
                "s3:PutObjectAcl"
            ],
            "Resource": "arn:aws:s3:::edtools-storage-railway/*"
        },
        {
            "Effect": "Allow",
            "Action": [
                "s3:ListBucket"
            ],
            "Resource": "arn:aws:s3:::edtools-storage-railway"
        }
    ]
}
```

## Troubleshooting

### Check S3 Configuration:
```bash
# In Railway console, run:
railway run rails runner "puts ActiveStorage::Blob.service.class"
# Should output: ActiveStorage::Service::S3Service

# Test file upload:
railway run rails runner "ActiveStorage::Blob.create_and_upload!(io: StringIO.new('test'), filename: 'test.txt')"
```

### Common Issues:
1. **Access Denied**: Check IAM permissions
2. **CORS Errors**: Configure CORS policy
3. **Public Access**: Ensure bucket allows public reads
4. **Region Mismatch**: Verify AWS_REGION matches bucket region

## Amazon SES Configuration

### 🚨 Security Recovery Steps (After Credential Compromise)

1. **Immediately rotate compromised credentials:**
   - Create new SES SMTP credentials in AWS Console
   - Create new S3 IAM user with fresh keys
   - Update Railway dashboard with new credentials
   - Delete old/compromised credentials from AWS

### 📧 SES Setup Guide

1. **Verify Domain/Email in SES Console:**
   ```bash
   # Go to AWS SES Console → Verified identities
   # Add your domain: edtools.co
   # Or add email: noreply@edtools.co
   ```

2. **Create SMTP Credentials:**
   ```bash
   # In SES Console → SMTP settings → Create SMTP credentials
   # Note: These are different from your regular AWS credentials
   # Username format: AKIA... (but different from S3 key)
   # Password: Generated by AWS (long string)
   ```

3. **SES Region Mapping:**
   ```bash
   # us-east-1 (N. Virginia): email-smtp.us-east-1.amazonaws.com
   # us-west-2 (Oregon): email-smtp.us-west-2.amazonaws.com
   # eu-west-1 (Ireland): email-smtp.eu-west-1.amazonaws.com
   ```

### 🔒 Railway Variables for SES

Set these in Railway dashboard (keep your existing values):
```bash
MAILER_SENDER_EMAIL=noreply@edtools.co
SMTP_ADDRESS=email-smtp.us-east-1.amazonaws.com  
SMTP_USERNAME=<NEW_SES_SMTP_USERNAME>
SMTP_PASSWORD=<NEW_SES_SMTP_PASSWORD>
```
